# Plano para CONTRIBUTING.md

Objetivo: explicar como contribuir para este repositório, descrito no README como sandbox para PRs de teste do agent-platform (fase 6e).

Estrutura proposta:

1. Propósito e escopo do repositório.
2. Preparação do ambiente e obtenção do código. Não inventar dependências ou comandos de instalação: `origin/main` contém apenas `README.md` e não apresenta configuração de build.
3. Fluxo de contribuição: atualizar a branch-base, criar uma branch descritiva, fazer uma alteração focada e abrir um PR para revisão. Confirmar as convenções específicas com os mantenedores antes de fixar nomes de branch, formato de commit ou critérios de aprovação.
4. Validação e testes: explicar como validar alterações de documentação; não anunciar comandos de teste automatizado enquanto o repositório não tiver infraestrutura de testes documentada.
5. Conteúdo esperado do PR: resumo da mudança, motivação e validações executadas.
6. Idioma e estilo: manter o CONTRIBUTING.md em português para acompanhar o README atual, salvo orientação diferente dos mantenedores.
7. Políticas e referências: incluir links para código de conduta, licença ou política de segurança somente se existirem ou forem aprovados; não criar regras por suposição.

Antes de redigir o guia, revisar o estado atualizado do repositório e confirmar com os mantenedores os detalhes de branch, revisão e testes que não estejam documentados.
